The project uses reusable React components to keep the UI consistent and maintainable.

Examples include:

* `SectionHeading`
* `Chip`
* `Reveal`
* Experience components
* Project components
* Navigation components

Portfolio information is separated into data files so that content can be updated without unnecessarily modifying UI components.
